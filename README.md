# 个人主页 · yugan-tano.github.io

陈杉杉的个人网站，像素风 + 浅粉浅蓝配色，托管于 GitHub Pages。

访问地址：https://yugan-tano.github.io

## 技术栈

- 纯静态 HTML / CSS / JavaScript（无框架依赖）
- 像素风 UI（像素机器人、云朵、星星动效）
- 响应式布局

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

```
├── index.html        # 主页面（照片墙 + 便签贴 + 技能 + 学习笔记）
├── style.css         # 样式与动画（拍立得质感、便签贴、响应式）
├── script.js         # 交互脚本（导航高亮）
└── assets/
    ├── covers/       # 项目像素风封面图
    └── photos/       # 头像、项目演示截图
```
